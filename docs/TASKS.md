# やることリスト (TASKS)

[PROJECT_OVERVIEW.md](./PROJECT_OVERVIEW.md) の準必須24pt構成（2026-10-06 に 43pt から縮小）に基づくタスクリスト。
フェーズ順に並んでいるが、フェーズ内のタスクは並行作業可能。
各フェーズ末の **DoD (Definition of Done)** を満たすまで次フェーズのモジュールを主戦場にしない
（「動かないモジュール = 0pt」対策として、常にデモ可能な状態を維持する）。

凡例: `[必須]` = subject の必須要件（落とすと rejected） / `(Npt)` = モジュールポイント

## スコープ外（縮小決定、2026-10-06）

チーム決定により準必須から外したモジュール（計 19pt）。経緯の記録として残す。理由は [PROJECT_OVERVIEW.md §3.5](./PROJECT_OVERVIEW.md) を参照。

- ユーザー交流 (Major 2) — 基本チャット削除。プロフィール/フレンドは標準ユーザー管理内に残る
- 高度チャット (Minor 1) — 基本チャット削除に伴い前提を失う
- 高度な検索 (Minor 1)
- トーナメント (Minor 1)
- 観戦モード (Minor 1)
- ゲーミフィケーション (Minor 1)
- 組織システム (Major 2)
- 公開 API (Major 2)
- ファイルアップロード (Minor 1)
- データ export/import (Minor 1)
- リアルタイム共同機能 / 共同検討盤 (Minor 1)
- リモートプレイヤー (Major 2) — 再接続要件の削除に伴い。対局自体は WebSocket でオンラインのまま
- ゲーム統計・対戦履歴 (Minor 1) — リーダーボード削除に伴い。結果の永続化と簡易な対戦履歴表示はモジュール申請なしで残す
- ブロックチェーン (Major 2) — トーナメント削除に伴い記録対象がなくなる
