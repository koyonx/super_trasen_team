# タスク分担 (TASK ASSIGNMENT)

チーム4人での担当割り。タスクの実体は [TASKS.md](./TASKS.md)、役職の定義は [ROLES.md](./ROLES.md) を参照。

## 前提

- 作業比重: **koyon >> 018re18 > ryu-lion**。**haru は BE 専任として独立**（比重の序列には含めない。BE 基盤の進捗で自律的に動く）
- haru は本人希望により **BE メイン**（GraphQL基盤・DB・認証まわり）
- 「主担当」は実装・完成・評価時のデモ/説明の責任者。「副担当」はレビュアー兼バックアップ
- 全員が必須パート（認証・コンテナ・バリデーション等）に何らかのコミットを持つこと（subject 要件）

## 運用ルール

1. 主担当はそのモジュールの **subject 要件文を満たしているか**を自己チェックし、PO (018re18) の検収を受ける。
2. 副担当（レビュアー）はエリアをまたぐこと: koyon⇔haru（BE基盤/エンジン）、018re18⇔ryu-lion（FE/API）を基本ペアとする。
3. 遅延・過負荷が見えたら PM (ryu-lion) が検知し、比重（koyon >> 018re18 > ryu-lion、haru は独立）を前提に再配分を提案する。
4. 全員、評価時に自分の主担当のデモ + 実装説明 + その場修正ができる状態を保つ。
